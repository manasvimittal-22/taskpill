# Security

TaskPill runs on your computer and talks to Claude Code through hooks on
`127.0.0.1` only. If you find a security problem (for example, a way for another
program or a web page to send events to TaskPill, or a way to make it run
something it shouldn't), please **don't open a public issue**. Report it
privately through GitHub instead: on this repository, go to **Security →
Report a vulnerability**.

Please include what you found, how to reproduce it, and which version you
used (right-click the tray icon → Settings shows it under Updates). You'll get
a reply as soon as possible, and a fix will be released before the problem is
made public.
